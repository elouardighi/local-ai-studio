# Local AI Studio

The project lives in this folder. The full documentation - what it does,
how to install it, and how to use it - is in the
[repository README](../README.md).

```
cd local-ai-studio
.\scripts\setup.ps1
.\scripts\start.ps1
```

Then open <http://127.0.0.1:1234>.
